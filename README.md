# Validus testbounty 001

Throwaway repo for testing the Validus Franklin plugin against a real
Base Sepolia USDC payout. Bounties live in `bounties.json`.

## Quick Start

1. Clone the repository.
2. Review `bounties.json` for active test bounties.
3. Create a branch and submit a PR that references the target issue (e.g. `closes #1`).

## What this repo is for

This is a tiny sandbox repository used to validate the end-to-end bounty flow (issue -> PR -> payout pipeline) on Base Sepolia USDC.
